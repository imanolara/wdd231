# FocusLab — WDD 231 Final Project

FocusLab is a lightweight, responsive study-technique library and session planner. It is built with semantic HTML, one shared CSS file, JavaScript ES modules, and a local JSON data source.

## Pages

- `index.html` — home page
- `techniques.html` — dynamic library with 18 items, filters, saved items, and an accessible modal
- `planner.html` — standards-based HTML form
- `review.html` — form action page that displays submitted data
- `attributions.html` — sources and acknowledgements

## Before submission

1. Copy this `final` folder into the root of your `wdd231` repository.
2. Replace the placeholder in `js/config.js` with the public URL of your finished video.
3. Update the **Final** link on the WDD 231 week 1 home page to point to `final/index.html`.
4. Commit and push the changes to GitHub.
5. Confirm GitHub Pages is enabled and open the full public URL in a private browser window.
6. Run Lighthouse in mobile and desktop modes, check the browser console, and test at 320 px wide.

The project uses no external libraries, fonts, or bitmap images. Its total transfer size is comfortably below 500 kB.

See `video-guide.md` for a timed recording script.
